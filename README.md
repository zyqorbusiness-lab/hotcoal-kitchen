# Hotcoal Kitchen

A fictional wood-fired pizzeria: a real-time 3D web concept by Zyqor Studio.
Watch a 3D pizza come together, fly into a brick oven as it bakes, build your own
with real photographic toppings, then "order" pickup (concept form, nothing is sent).

Concept site. Not a real restaurant; menu, prices, hours, address and phone are samples.

- Desktop: `index.html` - Phone build: `m.html` (auto-redirect by viewport/pointer; `?desktop=1` keeps the desktop page)
- Stack: static HTML/CSS/JS, three.js (MIT) from `vendor/`, real CC0/CC-BY photographs (see `credits.json` and the site footer)
- Live: https://hotcoal-kitchen.vercel.app/

Extracted 15 Nov 2026 from the Zyqor concept library (P041) into this standalone site.
